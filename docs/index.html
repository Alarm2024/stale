Why we built it

We sampled slot lag on RPC responses we were already using. Every quote was labelled fresh by the provider — stale measured the actual slot age against a reference endpoint.

Limits

  • Compares against one reference — if both endpoints lag equally, stale cannot tell.
  • Checks slot freshness, not whether account data is correct.
  • Read-only proxy — sendTransaction and requestAirdrop are refused.
  • WebSocket fan-out waits for v0.2.
